# 필요한 원본만 가져오기

[English](acquisition-workflow.en.md) · [사용 가이드](user-guide.ko.md) · [설치](alpha-installation.md)

작업에 필요한 범위와 자료를 고릅니다. 이미지를 먼저 보고 구조는 나중에 읽거나,
알려진 노드·하위 분기만 읽을 수 있습니다. **읽지 않은 노드를 없는 것으로 간주하지
않고, 미완료 자료를 완료로 표시하지 않습니다.**

## 가져올 방법 선택

| 작업 | 기능 | 완료가 뜻하는 범위 |
| --- | --- | --- |
| 작은 화면과 구조를 함께 검토 | Figma 선택 영역 가져오기 | 선택한 컨테이너의 한도 내 전체 하위 구조 |
| 큰 화면에서 먼저 영역 표시 | 미리보기만 → 미리보기로 초안 만들기 | 이미지 관찰만. 구조 확인·승인은 아직 불가 |
| 큰 영역의 전체 구조가 필요 | 원본 구조 수집 | 선택한 루트와 모든 하위 노드. 바깥 형제는 제외 |
| 알려진 노드 몇 개만 확인 | 필요한 원본 노드 읽기 | 요청한 ID와 필드만 |
| 바로 아래 노드를 보며 범위 탐색 | 바로 아래 노드 읽기 | 지정한 부모의 직접 자식만. 자손은 제외 |
| 필요한 분기 전체를 읽기 | 하위 영역 수집 | 선택한 분기의 루트와 모든 하위 노드 |

읽을 범위를 줄였으면 완료한 작업의 범위도 그에 맞춰 기록하세요. 작은 분기가
완료되어도 처음 요청한 큰 화면 전체를 처리했다는 뜻은 아닙니다.

## 1. 작은 화면 또는 미리보기 가져오기

1. 작업 공간을 열고 미저장 내용을 저장합니다. Figma 플러그인을 연결하고 읽을
   컨테이너 하나를 선택한 뒤 **Figma 선택 영역 가져오기**를 누릅니다.
2. 이름·경계와 가져오기 안내를 확인합니다. 아직 구조를 세거나 렌더링하지 않아
   전체 노드 수와 소요 시간을 모릅니다. 화면 크기만으로 시간을 추정하지 않습니다.
3. **가져올 내용**에서 다음 순서를 선택하고 **가져오기 시작**을 누릅니다.

| 선택 | 적합한 경우 |
| --- | --- |
| 미리보기 먼저, 원본 구조 나중 | 화면을 먼저 보고 같은 범위의 구조도 필요함 |
| 원본 구조 먼저, 미리보기 나중 | 원문·노드 정보가 우선임 |
| 미리보기만 | 이미지를 보고 구조가 필요한 범위를 결정하려 함 |
| 원본 구조만 | 이미지 없이 원문과 구조로 작업할 수 있음 |

작업은 표시된 원본에 고정됩니다. 이후 Figma 선택을 옮겨도 대상이 자동으로 바뀌지
않습니다. 이미지와 구조는 같은 시점의 관찰이 아니므로 읽는 동안 원본 편집을
피하고 두 결과를 비교하세요.

진행 중에는 단계·경과 시간·읽은 노드와 바이트를 표시합니다. 전체 분량을 모르므로
완료 퍼센트는 표시하지 않습니다. **미리보기 확대**는 이미 받은 이미지를
확대하며 Figma에 다시 렌더링을 요청하지 않습니다.

- 두 단계가 완성되면 **완료된 캡처 저장**을 누릅니다. 구조만 골랐다면 이미지 없이
  저장할 수 있습니다.
- 미리보기만 받았다면 **미리보기로 초안 만들기**로 제안 상태의 영역을 그립니다.
  원본 구조를 나중에 완성해 연결하기 전에는 매칭·확인·승인을 할 수 없습니다.
- **원본 구조 읽기**는 이미 받은 PNG를 재사용하되 작은 캡처 한도를 사용합니다.
  큰 구조가 필요하면 아래의 **원본 구조 수집**을 선택하세요.

한 단계가 실패해도 성공한 결과는 남습니다. **미리보기 다시 시도** 또는 **원본 구조 처음부터 다시 읽기**는 해당 단계만 다시 시작합니다. 구조 재시도는 처음부터 읽습니다. 같은 한도로
계속 잘린다면 반복하지 말고, 필요한 범위를 명시적으로 줄이거나 구조 수집으로 바꾸세요.

## 2. 큰 구조 수집과 이미지 연결

**원본 구조 수집**을 열고 Figma에서 선택한 컨테이너를 확인합니다. 최대 노드·자료
한도와 Figma 내부 작업의 불확실성을 읽은 뒤 시작하세요.

- 최대 **500개 노드·1MB씩** 저장합니다. 전체 한도는 **20만 노드·64MB**입니다.
  미리 전체 개수를 세지 않으며 받은 노드 수·바이트·시간을 표시합니다.
- 일시정지는 현재 묶음을 저장한 뒤 적용됩니다. 한 실행이 5분에 도달하면 묶음
  사이에서 자동으로 멈춥니다. 저장한 묶음은 재개 시 다시 읽지 않습니다.
- 재개에는 같은 유효한 플러그인 세션과 원본이 필요합니다. 유휴 10분, 페이지 변경,
  재연결·앱 재시작 등으로 순회 상태를 잃으면 새 수집이 필요합니다.
- 전체 구조의 누락·중복·부모 관계 검증을 통과해야 완료됩니다. 완료된 구조만
  작업 공간의 원본·확인·승인에 사용합니다.

완료하면 **작업 공간에 원본 구조 추가**로 이미지 없이 사용할 수 있습니다.
**현재 이미지 초안에 연결**은 파일·페이지·루트·경계가 같은 초안에만 연결합니다.
기존 이미지와 영역 초안은 유지되지만 이미지와 구조가 동일 버전이라는 보장은
없습니다. 연결한 주석은 항상 저장된 노드 집합을 사람이 **원본 확인**해야 승인됩니다.

완료된 자료의 노드 목록은 페이지별로, 원문은 해당 노드를 고를 때 읽습니다.
캔버스에 불러온 경계 수와 전체 수집 노드 수는 별도로 표시합니다. 화면에 모든
경계가 없다고 자료에서 누락된 것은 아닙니다.

## 3. 특정 노드와 하위 영역만 읽기

**필요한 원본 노드 읽기**에서 조사할 원본을 준비합니다.

- **노드 정보만**는 최대 100개 ID의 메타데이터를 읽습니다. **노드 정보와 원문**을
  고를 때만 해당 TEXT 원문도 읽습니다.
- **바로 아래 노드 읽기**는 부모 ID를 지정하고 다음 목록을 요청하며 탐색합니다.
  각 응답은 최대 100개이며, 손자 이하를 읽었다고 간주하지 않습니다.
- **하위 영역 수집**은 필요한 컨테이너의 분기만 완전히 읽습니다. 이 결과는 위의
  구조 수집처럼 완료 후 원본으로 사용할 수 있습니다.

이미 저장된 같은 요청의 결과를 재사용하는 경우 Figma를 다시 읽지 않습니다.
캐시 재사용은 현재 디자인과 같다는 증명이 아니므로 변경 후에는 새 조사를 시작하세요.
Figma가 큰 부모의 `children` 배열 전체를 내부적으로 만들 수 있어 응답을 나눈다고
Figma 내부 메모리까지 같은 크기로 제한되는 것은 아닙니다.

## 중단·오류·자료 정리

**Figma 가져오기 중단**은 대기와 중단 가능한 읽기를 멈춥니다. 이미 실행 중인 Figma
이미지 내보내기는 즉시 끝낼 수 없습니다. 결과가 늦게 도착하면 사용하지 않으며,
플러그인은 잠시 바쁠 수 있습니다. 창 닫기나 새로고침은 중단 버튼을 대신하지 않습니다.

이전 결과는 **최근 가져오기**에서 확인합니다. **가져오기 기록 삭제**는 해당 캐시만
삭제하며 저장된 캡처·주석은 유지합니다. 이미지 초안이 사용하는 기록과 작업 공간이
참조하는 구조 수집은 삭제할 수 없습니다. 수집 기록은 서버 전체 12개·256MB,
가져오기 기록은 최대 12개입니다. 다른 작업 공간의 자료는 그 공간에서 정리하세요.

커서 해제를 확인하지 못하면 재시도에 필요한 기록을 보존합니다. 같은 작업의 해제나
제거를 다시 시도하거나 플러그인을 다시 연결한 뒤 새로 시작하세요. 한도 초과·손상·
세션 변경을 단순 대기 문제로 여기고 같은 요청을 반복하지 마세요.

## 한도와 판단 기준

| 항목 | 한도·주의점 |
| --- | --- |
| 작은 캡처의 구조 읽기 | 기본 5,000노드·2MB·협력적 5초. 초과 시 미완료 |
| 미리보기 | 긴 변 최대 2,048px·8MB. 큰 표의 작은 글씨는 원문으로 확인 |
| 현재 노드 이미지 비교 | 최대 1,024px·2MB·협력적 5초. 바깥 형제 레이어는 제외 |
| 원본 파일 | 완료된 구조 하나와 선택적 이미지, 최대 80MB NDJSON. 주석·명세·승인 제외 |
| 작은 캡처 전달 | 최대 두 캡처, 합계 노드 10,000개·노드 정보 4MB·파일 15MB |
| Section·변형된 루트 | 이미지 미지원 시 구조만 보존하거나 회전하지 않은 내부 Frame을 명시적으로 선택 |

앱의 시간·응답 한도는 Figma의 페이지 로딩, 렌더링 시간과 최대 메모리를 보장하지
않습니다. 이 앱의 경로에는 Figma REST API나 PAT가 필요하지 않습니다. REST 우회나
동시에 여러 렌더링을 실행하는 대안은 자동 적용하지 않습니다.

원본 파일 전달은 **원본 파일** 패널을 사용합니다. 가져올 때 체크섬·종료 표시·전체
구조를 검증한 뒤 미검토 원본 범위를 추가합니다. 승인 결과나 전체 작업 공간 백업은
포함하지 않습니다. 자세한 검토 순서는 [사용 가이드](user-guide.ko.md)를 보세요.
