# v0.5.0 — mandatory user-task acceptance (bookmarklet architecture)

**Normative.** Test user outcomes and persisted state, not merely rendered controls or resemblance to the [reference-only sketch](../../reference-only/README.md). Product contract: [v0.5 plan](v0.5.0-replacement.md). All tests below supersede the former plugin-based acceptance; **there is no plugin in v0.5**.

Fixtures: two Figma files F1/F2, pages P1/P2, UI nodes A–E and Spec S1/S2; repeated names, negative/fractional BBoxes, a Spec linked across files. Synthetic API fixtures are acceptable in CI; actual Figma web and REST/MCP gates require separate real evidence.

**T01 — PAT gate and workspace.** On clean startup with no PAT, only token entry is available; workspace/editor cannot open. Invalid token or missing required scope blocks with a concise error. Valid token is server-side persisted with restricted permissions; refresh/restart goes to workspace create/select/delete. Without active workspace, Canvas/Regions cannot be used. Token is absent from browser storage, bookmarklet, logs, JSON and MCP.

**T02 — Single bookmarklet, in-app kind choice.** In Figma web Dev Mode select A and click the *one* bookmarklet. It opens/reuses named Bridge window and transfers the current URL with unique nonce. Bridge shows UI/Spec choice; choose UI and exactly one import begins, with no extra confirmation. Cancel does not import. Repeat for S1 and choose Spec. No plugin, CDP, token in bookmarklet, kind-specific bookmarklets, CORS fetch from Figma or separate workspace selector. Test initial load, already-open window, same-node repeat, new selection, popup permission and hashchange behavior in a real browser.

**T03 — Node URL fidelity and identity.** In actual Figma web Dev Mode select at least 20 representative nodes, including Frame, Group, Text, Instance and Variant where available. Assert URL `node-id` matches intended selection or record precisely which kinds fail. Reject missing/malformed/unsupported URL rather than importing the wrong node. Figma fileKey+nodeId uniquely identifies source, with page provenance derived/verified by REST. Same source+kind resend preserves human name, local adjustments, hierarchy and edges while refreshing source metadata; same source may exist as both UI and Spec. Different fileKey is distinct.

**T04 — REST and blocking errors.** With valid PAT, selected node REST lookup (bounded depth) returns usable identity, BBox, name and page provenance; only then persist region. With 401/403/404, wrong token, inaccessible file or invalid URL, do not persist a new region. Authentication/permission error shows token re-entry modal or actionable access error and blocks the import. Cancel aborts; no pending queue, offline mode or delayed lookup. After valid replacement token, explicitly retry the current action; do not silently mutate a different workspace. Never call arbitrary URLs from the import fragment.

**T05 — Async image isolation.** After successful node metadata lookup, image fetch may complete later or return null/error. Region remains usable and shows a placeholder; successful image eventually appears at correct BBox/aspect ratio. A stale image result cannot overwrite a newer resend or another workspace. Verify Figma image API parameters, null responses and no silent stretching.

**T06 — Canvas and editing.** Import A/B in F1/P1, C in F1/P2 and D in F2/P1. File/page selector separates coordinates, preserves relative original positions; fit/pan/zoom handle negative/fractional BBoxes. Select region, type name immediately, adjust local bounds, delete, and reload without a Save button. Text editing is not hijacked by canvas shortcuts. Switching pages does not alter semantic relationships.

**T07 — Unrestricted order and persistence.** Rename in Canvas, switch to Regions, reorganize UI, return, import a Spec, rename and export. No wizard, approval, source matching, candidate search or mandatory inspector. Tabs preserve useful selection/scroll state; changes survive browser and server restart. UI and Spec lists scroll independently.

**T08 — UI hierarchy.** In Regions, nest A under B, B under C, C under D and reorder siblings; verify unlimited-depth semantics, stable order and persisted tree. Reject moving D under A (cycle), and reject UI under Spec. Move B to root without losing descendants. Test real pointer drag/drop and keyboard-accessible alternative.

**T09 — Spec ghosts N:N.** Drag S1 from Spec catalog under UI B and D across files; S1 remains in Spec catalog and appears as two ghost references. Duplicate drop is idempotent. Unlink under B removes only that edge, not S1 or D edge. Deleting S1 deliberately removes its edges without affecting UI hierarchy. Reload and verify.

**T10 — JSON and MCP semantic contract.** Export and read-only MCP contain the same stable Bridge IDs, Figma fileKey/pageId/nodeId/canonical URL, human name/description, ordered UI hierarchy and N:N relations. Exclude PAT, PNG, BBox, text hints, raw Figma text, styles, source trees and filesystem paths. Real downstream Figma MCP dereferences a UI and Spec node independent of current Figma selection; if inaccessible, mark unverified, not passed.

**T11 — CLI and recovery without complexity.** Clean clone → npm ci → npm run build → npm start; printed loopback URL works, data survives restart, duplicate port fails clearly, no Xcode/Swift/Electron/DMG/plugin/cloud/DB daemon. Invalid bookmarklet fragment, stopped server, expired PAT and failed image produce concise errors; previously persisted edits remain intact. Next valid import needs no pairing or recovery wizard.

**T12 — Human comprehension.** With only the initial instruction and one bookmarklet, a new tester selects two UI nodes and one Spec in Figma, chooses kinds in Bridge, names them, nests UI, links Spec to both, and exports. Observe hesitation, errors and whether tasks complete without explanations of implementation states. Record qualitative results and fix/retest blocking ambiguity; do not substitute screenshot similarity or invented usability metrics.

## Test evidence and exit

Unit: schemas, identity, PAT storage redaction, tree invariants, N:N uniqueness, async image races, persistence, export exclusions.
Browser E2E: T01–T02 (synthetic navigation), T04–T11, actual drag/drop, keyboard and restart, not direct store mutation.
HTTP/REST integration: real loopback server with mocked Figma HTTP for error matrix; fixed Figma API destinations and bounded requests.
Real browser/Figma: T02–T05 actual Figma web selection, bookmarklet, REST and images; T10 actual Figma MCP.
Human UX: T12 with observations.

Each phase reports commands, environment, commit SHA, passed/failed/unverified gates. **Do not declare v0.5 done if mandatory real Figma selection URL fidelity, bookmarklet delivery, page provenance or Figma MCP dereference remains unverified.** On a failed P0 architecture gate, document the blocker and request owner decision; do not silently switch to a plugin, CDP or DOM scraping.
