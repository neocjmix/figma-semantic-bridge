# 0.1.0 알파

**독립 앱의 로컬 설치·실행 검증을 완료했다. 공개 릴리스는 아직 게시되지 않았으며
소유자의 LICENSE 선택을 기다린다.** 다운로드 URL은 게시 예정이다. 최종 커밋과
asset 체크섬을 고정한 뒤 README에 실제 링크를 추가한다.

Figma 원본을 변경하지 않고 선택한 범위를 로컬에 캡처한 뒤, 사람이 의미 영역과
명세를 검토·승인하여 MCP로 전달하는 첫 알파다. 앱에 공식 Node.js **22.23.4 arm64**,
빌드된 서버·웹·MCP와 로컬 Figma 플러그인이 포함되어 사용자가 checkout이나
Node/npm 설치, 개발 서버를 준비할 필요가 없다.

## 설치 구성

| 구성 | 생성된 로컬 후보 |
| --- | --- |
| macOS DMG / 앱 ZIP | `figma-semantic-bridge-0.1.0-macos-arm64.dmg` / `.zip` |
| 앱 | `Figma Semantic Bridge.app`; macOS 13+ Apple Silicon 빌드 대상 |
| Figma 플러그인 | `figma-semantic-bridge-plugin-0.1.0.zip` 및 `.zip.sha256`; prebuilt 로컬 개발 플러그인 |
| 안내와 무결성 정보 | 오프라인 설치 Markdown/HTML, `SHA256SUMS`, release JSON, 포함 런타임/의존성 고지 |
| 실제 사용 안내 | [한국어 설치·운영 안내](../alpha-installation.md), 번들 Node를 쓰는 MCP 설정 포함 |

앱은 **ad-hoc 서명**이며 Apple Developer ID 배포 서명과 공증은 없다. 개인
Apple Development 인증서를 배포용으로 사용하지 않았다. macOS 최초 실행은
앱별 사용자 허용 절차를 따르며 보안 설정을 자동 해제하지 않는다.

내장 WKWebView 편집기는 로컬 서비스에 자동 페어링되므로 외부 브라우저가 필요 없다.
메뉴에서 오프라인 안내, 플러그인/데이터 위치, 토큰 복사와 MCP 설정을 제공한다.
호환되는 기존 서버만 재사용하며 종료 시 자신이 시작한 서버만 중지한다.
Figma 플러그인이 닫혀도 앱이 실행 중이면 기존 캡처와 승인 결과를 읽을 수 있다.

## 포함하는 기능

- 선택한 컨테이너의 bounded 메타데이터/PNG 캡처, 좌표·원문·출처·경고 보존.
- 영역 그리기/수정, 결정적인 source 후보 매칭, 모호성·렌더링 unknown 표시.
- Figma에서 확인한 참조를 Add → Save → Confirm하고 의미를 별도 승인하는 흐름.
- 저장 crop과 현재 단일 노드/subtree PNG 비교, 확대 보기, 취소·stale 결과 보호.
- 여러 캡처의 정확한 명세 원문과 구성요소 연결, 승인 결과 JSON/Markdown과 MCP 읽기.
- 원본 캡처 최대 두 개의 portable bundle 내보내기/새 workspace 가져오기.
  캡처 소비자는 Figma/Dev seat 없이 로컬에서 검토할 수 있다.
- 로컬 atomic JSON 저장, revision 충돌 보호, bounded undo/redo, 승인된 자료의 AI 덮어쓰기 방지.
- 선택적인 AI 제안은 기본 비활성화. 제안 수락은 의미 승인이 아니며 MCP는 승인하지 않는다.

## 실제 설치 앱 검증

`/Applications`에 설치한 앱의 번들 Node로 다음을 실행했다. 원문·개인 경로·식별자·
이미지를 제외한 [공개 집계](../evaluation/alpha-desktop-acceptance.json)가 있다.

| 검증 | 관측 결과 |
| --- | --- |
| 기존 서비스 충돌 | 호환되지 않는 checkout 서비스를 정확히 거부. 작업 소유 LaunchAgent만 명시적으로 중지·백업한 뒤 전환 |
| 데이터 보존 | 기존 6개 프로젝트 hash 유지; 설치가 기존 승인을 변경하지 않음 |
| 앱 편집기 | WKWebView 자동 페어링, 합성 주석 저장 |
| 파일 작업 | native 저장 대화상자로 JSON/Markdown 저장, 두 캡처 bundle 파일 내보내기와 native 파일 열기 가져오기 |
| Figma | 설치 앱 Resources의 manifest 실제 import, 소유 합성 파일의 Dev Mode에서 21개 노드와 800×600 PNG 완전 캡처; 원본 수정 없음 |
| 번들 MCP | 설치된 Node/MCP로 `list_projects`, `get_approved_context` 실제 호출 성공 |
| 종료·재시작 | Cmd-Q 뒤 앱 소유 4177 listener 없음. 재실행 자동 페어링, 토큰·프로젝트 hash 유지, 저장 주석 화면 재열기 |
| 자동 검사 | 전체 Node 테스트 187/187, TypeScript·빌드 통과; 브라우저 23/23 통과 |

오프라인 안내 창의 열기는 확인했다. 최종 번들의 guide GUI 관측은 별도 로컬 증거에,
clean-commit 검증과 실제 asset SHA는 동봉된 verification JSON에 기록한다.
이 문서에 아직 실행하지 않은 최종 후보의 성공이나 hash를 미리 쓰지 않는다.
이 Mac에는 개발 도구가 이미 있었으며 실행 경로가 번들 Node였음을 확인했다.
다른 초기화된 Mac의 최초 다운로드·Gatekeeper 경로나 macOS 13 실행을 검증한 것은 아니다.
합성 데이터 조작은 에이전트의 제품 수용 시험이며 독립 사용자 의미 평가가 아니다.

기존 native geometry, 네 가지 current-node export, pending cancel/close, controlled
timeout·복구, 두 파일 교체, 30회 성능 측정과 3회 제외 warmup, analyzer 네 scope
기록은 [제품 validation](../product-validation.md)에 별도로 보존한다.

## 알파의 경계

- macOS 13은 빌드 하한이다. 실제 관측 환경은 macOS 26.6.2, Figma Desktop 126.10.11,
  Chrome 155.0.8059.85이며 다른 OS/CPU에서 실행된 것으로 확대하지 않는다.
- 플러그인은 Figma Desktop의 로컬 개발 manifest 가져오기 방식이다. private fileKey
  API에 의존하며 Community 등록이나 조직 내부 배포가 완료된 것은 아니다.
- 목표는 Dev seat + can-view 원본 접근이다. 소유 파일의 Dev Mode 성공과 다른 소유자의
  파일에서 실효 Dev-only 계정으로 사용할 수 있다는 검증은 다르다.
- SECTION과 지원하지 않는 변형 root는 메타데이터만 보존한다. 이미지가 필요하면
  회전하지 않은 내부 Frame을 선택한다.
- 캡처는 시점별 관측이다. 자동 동기화/reconciliation, 가림·옛 디자인 자동 판정,
  완전한 스타일/하위 노드 변경 검출이나 전체 파일 사전 로딩은 제공하지 않는다.
- current export는 1024px/2MB/협력적 5초 제한이다. 결과를 버리는 취소와 Figma 내부
  작업 중단은 다르며 native export/메모리를 강제 중단·제한할 수 없다.
- 로컬 파일은 평문이다. 기업 자료의 외부 AI 전송에는 별도 명시적 허용과 조직 정책이
  필요하다. 설치·검증 중 자동 전송하지 않는다.
- 자동 업데이트·모든 향후 스키마 마이그레이션·다운그레이드 호환성은 보장하지 않는다.
  앱 변경 전 서버를 중지하고 데이터 폴더 전체를 백업한다.
