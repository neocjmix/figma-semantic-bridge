## 한국어

0.1.1은 한국어·영어 인터페이스와 오프라인 안내를 제공하는 후속 알파다.
**0.1.1 후보 패키지와 0.1.0 → 0.1.1 실제 로컬 업데이트 검증을 완료했다.
[0.1.1 공개 알파](https://github.com/neocjmix/figma-semantic-bridge/releases/tag/v0.1.1-alpha)를 게시했다.**
MIT를 적용했으며 로컬 인증·입력 검증 문제는
[앱 인증 #11](https://github.com/neocjmix/figma-semantic-bridge/issues/11),
[플러그인 인증 #12](https://github.com/neocjmix/figma-semantic-bridge/issues/12),
[캡처 검증 #13](https://github.com/neocjmix/figma-semantic-bridge/issues/13)에서
미수정 제한으로 추적한다. 실제 asset checksum은 릴리스의 `SHA256SUMS`와
verification JSON에 있다.

수정 전에는 본인 소유의 합성·비민감 파일로만 평가하고 사내·고객 디자인이나
신뢰할 수 없는 캡처 묶음을 사용하지 않는다. 로컬 설치형 플러그인이며 Figma
Community 등록은 이번 배포 대상이 아니다.

### 이번 버전의 사용자 기능

- 웹 편집기의 **Language / 언어**에서 한국어 또는 영어를 선택하고 저장한다.
- macOS 앱의 메뉴·편집기 언어를 동기화하고 재실행 후 선택을 유지한다.
  첫 기본값은 macOS의 첫 번째 선호 언어를 따르며 브라우저는 자신의 언어를 참고한다.
- Figma 플러그인은 자신의 언어 선택을 별도로 저장한다.
- 두 언어의 설치 가이드, 작업 순서·상황별 사용자 가이드와 README를 제공한다.
  앱의 **설치 가이드(Setup Guide)**와 **사용 가이드(User Guide)**는 오프라인으로 열린다.
- 언어 전환은 작성 중인 주석을 초기화하거나 프로젝트 이름, Figma 노드 이름·원문,
  명세, 저장된 승인 콘텐츠를 번역하지 않는다.

원본 Figma를 수정하지 않는 캡처 → 원본 참조 검토 → 출처 확인 → 의미 승인 →
JSON/Markdown·MCP 전달 흐름은 유지한다. 출처 확인과 의미 승인은 사람의 별도 판단이다.
AI 제안 수락이나 언어 전환은 어느 판단도 대신하지 않는다.

### 설치 구성과 0.1.0에서 업데이트

| 구성 | 0.1.1 파일/조건 |
| --- | --- |
| 앱 | `Figma Semantic Bridge.app`; macOS 13+ Apple Silicon 빌드 대상 |
| 앱 배포본 | `figma-semantic-bridge-0.1.1-macos-arm64.dmg` / `.zip` |
| 플러그인 | `figma-semantic-bridge-plugin-0.1.1.zip`; 미리 빌드된 로컬 개발 플러그인 |
| 런타임 | 공식 Node.js 22.23.4 arm64, 제품 서버·웹·MCP 포함 |
| 안내 | 한국어·영어 설치/사용 Markdown 및 앱 내부 오프라인 HTML |
| 무결성 | `SHA256SUMS`, release JSON, 실제 패키지를 검사한 verification JSON |

기존 설치가 있으면 신규 설치를 반복하지 않는다. 저장 후 앱·플러그인·관련 writer를
정상 종료하고 데이터와 앱을 **복사해서** 백업한다. 설치된 앱을 이동하거나 이름을
바꾸면 Figma 북마크가 이전 사본을 따라갈 수 있다. 앱의 루트 디렉터리 정체성을
유지한 채 내용을 교체하고, 플러그인 등록이 같은 현재 manifest를 가리키는지 확인한다.

업데이트는 기존 프로젝트·캡처·승인 이력·토큰과 언어 선택을 보존해야 한다.
앱 설정·브라우저 저장소·Figma 플러그인 저장소를 초기화하지 않는다. 0.1.0 서비스가
남아 있으면 버전 호환 오류가 날 수 있으므로 정상 종료하며, 토큰 재발급이나 다른
사용자 프로세스 강제 종료로 해결하지 않는다. 정확한 절차와 인수 기준은
[설치 가이드 9절](../alpha-installation.md#9-백업업데이트복원)에 있다.

실제 설치 앱은 자동 페어링됐고 한국어·영어 메뉴 전환 중 미저장 혼합 언어 입력을

언어 전환 뒤 같은 연결 세션을 유지했다. 설치 번들 MCP의 `get_selected_node`가
실제 선택을 읽었다. 원본 Figma는 수정하지 않았다.
이전 0.1.0의 21개 노드 저장 합성 캡처를 0.1.1에서 읽기 전용으로 열었고,
프로젝트 파일 hash가 여전히 같음을 확인했다.

[0.1.1 공개 집계](../evaluation/release-0.1.1-acceptance.json)는 최종 문서 커밋 전에
관측한 후보를 기록한다. 최종 clean commit에서 다시 생성하는 패키지의 결과는
`figma-semantic-bridge-0.1.1-verification.json`이 source revision과 실제 asset SHA에
연결한다. 문서에 최종 hash를 미리 적거나 새 패키지를 같은 native 시험 결과로 간주하지 않는다.

[0.1.0 릴리스 기록](0.1.0.md), [설치 앱 관측](../evaluation/alpha-desktop-acceptance.json),
[다국어 관측](../evaluation/bilingual-interface-acceptance.json)의 버전과 사실은 역사로 보존한다.
에이전트의 합성 수용 시험은 독립 사용자 의미 정확도나 생산성 평가가 아니다.

### 유지되는 알파 제한

- macOS 13은 빌드 하한이며 해당 OS에서 실행한 증거가 아니다. 이전 실제 관측은
  macOS 26.6.2와 Figma Desktop 126.10.11이다. Intel·Windows·Linux 앱은 포함하지 않는다.
- ad-hoc 서명이며 Apple Developer ID 서명·공증은 없다. Gatekeeper나 격리 속성을
  자동 해제하지 않는다. 조직 정책과 사용자 OS 확인을 따른다.
- Figma Desktop의 로컬 개발 manifest 가져오기를 사용한다. Community 공개 플러그인이
  아니며, 타인 소유 can-view 파일의 실효 Dev-only 계정 조합은 별도 미검증이다.
- SECTION과 지원하지 않는 변형 root는 이미지 없이 메타데이터를 보존한다.
  현재 노드 PNG는 바깥 형제·전체 가림·최신 디자인 여부나 완전한 변경 검출을 입증하지 않는다.
- 데이터는 로컬 평문이다. 기업 자료의 외부 AI 전송에는 별도 명시적 허용이 필요하다.
  패키지 앱의 외부 AI 생성은 기본 비활성이다.
- 자동 업데이트나 모든 향후 데이터 마이그레이션·다운그레이드는 보장하지 않는다.

## English

0.1.1 is the follow-up alpha for Korean/English interfaces and offline guidance.
**The 0.1.1 candidate package and actual local update from 0.1.0 passed verification.
The [0.1.1 public alpha](https://github.com/neocjmix/figma-semantic-bridge/releases/tag/v0.1.1-alpha) is published.**
The project is MIT licensed. Local authentication and input-validation findings
remain open in [desktop #11](https://github.com/neocjmix/figma-semantic-bridge/issues/11),
[plugin #12](https://github.com/neocjmix/figma-semantic-bridge/issues/12) and
[capture validation #13](https://github.com/neocjmix/figma-semantic-bridge/issues/13).
The release's `SHA256SUMS` and verification JSON record actual asset checksums.

Until fixed, evaluate only with your own synthetic or non-sensitive files. Do
not use corporate or client designs or import untrusted capture bundles. This
package uses a locally imported Figma development plugin, not Community listing.

### User-facing changes

- Choose and save Korean or English with **Language / 언어** in the web editor.
- Native macOS menus and the embedded editor synchronize their language and retain
  the choice across restart. The app initially follows the OS's first preferred
  language; a separate browser follows its own language preference.
- The Figma plugin retains an independent language choice.
- English and Korean installation guides, situation-based user guides and README
  files accompany the app. **Setup Guide** and **User Guide** open offline.
- Switching language preserves unsaved work. It never translates project names,
  Figma node names, original text, specifications or approved content.

The source-preserving capture → source review → human source confirmation → human
semantic approval → JSON/Markdown or MCP workflow remains. Accepting an AI draft
or changing language performs neither human decision automatically.

### Installation and update

Use `figma-semantic-bridge-0.1.1-macos-arm64.dmg` or the app ZIP for the Apple Silicon
macOS 13+ build target. The app includes official Node.js 22.23.4 arm64, built
server/web/MCP assets and a prebuilt local Figma plugin. The separate plugin ZIP is
`figma-semantic-bridge-plugin-0.1.1.zip`. Users need no checkout or system Node/npm.
The distribution includes bilingual guides, `SHA256SUMS`, release metadata and a
verification report for the artifacts actually checked.

Skip repeated first-time installation when updating 0.1.0. Save work, normally stop
the app, plugin and relevant writers, then **copy** the app and data for backup.
Moving or renaming the installed app can make Figma's bookmark follow the old copy.
Keep the application root directory identity intact while replacing its contents;
confirm Figma's registration still resolves to the current manifest.

Preserve projects, captures, approvals, the token and language choices. Do not clear
native preferences, browser storage or Figma plugin storage. A remaining 0.1.0 service
can fail the new version's compatibility check; stop the identified old service
normally rather than regenerating the token or killing unrelated processes.
See [installation section 9](../alpha-installation.en.md#9-backup-update-and-restore)
for the full procedure and acceptance checklist.

### Continuing alpha boundaries

- macOS 13 is the deployment target, not a verified execution environment. Earlier
  observations used macOS 26.6.2 and Figma Desktop 126.10.11. No Intel, Windows or Linux app is included.
- The app is ad-hoc signed, without Apple Developer ID signing or notarization.
  Do not disable Gatekeeper or remove quarantine attributes; respect OS confirmation and policy.
- Figma Desktop uses local development-manifest import, not Community publication.
  A Dev-only account on another owner's can-view file remains separately unverified.
- SECTION and unsupported transformed roots retain metadata without images.
  Current-node PNGs do not establish outside-sibling occlusion, newest-version identity
  or complete change detection.
- Data is local plaintext. Corporate-design transfer to external AI needs separate
  explicit authorization. External AI generation is disabled by default in the app.
- Automatic updates and every future migration or downgrade are not guaranteed.
