# 0.2.0 Alpha

[한국어 사용 가이드](../user-guide.ko.md) · [English user guide](../user-guide.en.md)

## 한국어

큰 Figma 프레임을 필요한 범위부터 불러오고, 원본을 확인한 뒤 승인된 구현 맥락을
전달할 수 있습니다. 한국어·영어 화면과 설치·사용 가이드도 실제 작업 순서에 맞춰
다듬었습니다. 앱의 사용 가이드에는 합성 예시 화면이 포함되며 오프라인으로 볼 수 있습니다.

- **미리보기부터 시작:** 이미지를 먼저 확인하고 영역 초안을 만들 수 있습니다.
  미리보기만으로 원본 연결이나 승인이 완료되지는 않습니다.
- **필요한 원본부터 읽기:** 선택한 노드의 정보·원문, 바로 아래 노드 목록, 선택한
  하위 영역의 구조를 따로 불러옵니다. 큰 구조는 나누어 저장하고 진행 상태를 표시합니다.
- **누락을 감추지 않는 검토:** 미완료 자료는 미완료로 표시합니다. 원본 구조를
  완전히 불러오고 사람이 연결된 원본을 확인한 뒤 승인·명세 연결·내보내기에 사용합니다.
- **원본 자료 전달:** 완료된 구조와 선택적 미리보기를 NDJSON으로 내보내고 다시
  가져올 수 있습니다. 이 파일은 승인·주석을 포함하는 작업 공간 백업이 아닙니다.
- **연결과 입력 검증 강화:** 앱·MCP의 로컬 인증서 확인, 플러그인의 상호 인증·메시지
  암호화, 큰 입력의 검증 순서를 개선했습니다. 기존 [#11](https://github.com/neocjmix/figma-semantic-bridge/issues/11),
  [#12](https://github.com/neocjmix/figma-semantic-bridge/issues/12),
  [#13](https://github.com/neocjmix/figma-semantic-bridge/issues/13) 수정이 포함됩니다.

### 설치와 업데이트

[0.2.0 알파 다운로드](https://github.com/neocjmix/figma-semantic-bridge/releases/tag/v0.2.0-alpha)에서
Apple Silicon용 DMG 또는 앱 ZIP을 받으세요. 앱에 Node.js와 Figma 플러그인이 포함되어
별도 개발 환경이 필요하지 않습니다. 처음 설치할 때는 [설치 가이드](../alpha-installation.md),
0.1.x에서 올릴 때는 [업데이트 가이드](../upgrade-guide.md)를 따르세요.

**앱과 플러그인을 함께 업데이트해야 합니다.** 기존 작업을 저장하고 앱·플러그인을
종료한 뒤 데이터와 앱을 복사해 백업하세요. 플러그인 등록 경로와 로컬 데이터를
보존하고, MCP 설정은 새 앱의 **브리지 → MCP 설정 복사**로 갱신하세요.
0.1.1 배포 파일은 교체하지 않으며 이 수정이 포함되지 않습니다.

### 알파에서 알아둘 점

앱은 ad-hoc 서명이며 Apple 공증은 없습니다. macOS 13 이상을 빌드 대상으로 하는
Apple Silicon 배포본입니다. 타인 소유 읽기 전용 파일의 Dev 전용 계정 조합과
문제를 제보한 대형 실무 파일의 전체 재검증은 아직 별도 확인이 필요합니다.
가려진 옛 레이어나 최신 디자인의 의도는 자동으로 확정하지 않으므로 Figma에서
직접 비교하세요. 조직 자료 사용은 조직의 허용 범위와 보안 정책을 따르세요.

패키지의 실제 커밋·파일 해시는 릴리즈에 첨부한 `release.json`, `SHA256SUMS`,
`verification.json`에서 확인할 수 있습니다. [검증 기록](../evaluation/release-0.2.0-acceptance.md)은
자동 검사와 실제 앱·Figma 관측의 범위를 구분합니다.

## English

Load the parts of a large Figma frame that your task needs, review their source
connections and share approved implementation context. Korean and English UI copy
and setup/workflow guides now follow the user's task. The app's offline user
guides include screenshots made with synthetic example data.

- **Start with a preview.** View the image and draft regions before loading
  structure. An image alone does not establish source connections or approval.
- **Read only what you need.** Fetch selected node details or original text,
  immediate children, or a chosen branch separately. Large structures are saved
  in parts with progress feedback.
- **Keep incomplete work visible.** Partial results stay marked incomplete.
  Complete the source structure and confirm its connections before using it for
  approval, specification links and approved exports.
- **Transfer source files.** Export and import a completed structure with an
  optional overview as NDJSON. This is not a workspace backup and does not include
  annotations or approvals.
- **Stronger local connections and validation.** This release adds private
  certificate verification for the app/MCP, mutual authentication and encrypted
  plugin messages, and early bounds checks for large inputs. It includes fixes
  for [#11](https://github.com/neocjmix/figma-semantic-bridge/issues/11),
  [#12](https://github.com/neocjmix/figma-semantic-bridge/issues/12) and
  [#13](https://github.com/neocjmix/figma-semantic-bridge/issues/13).

### Install or update

Download the Apple Silicon DMG or app ZIP from the
[0.2.0 alpha release](https://github.com/neocjmix/figma-semantic-bridge/releases/tag/v0.2.0-alpha).
Node.js and the local Figma plugin are bundled; no development environment is
needed. Follow the [setup guide](../alpha-installation.en.md) for a first install
or the [upgrade guide](../upgrade-guide.md) when updating 0.1.x.

**Update the app and plugin together.** Save your work, quit both, and copy the app
and local data for backup. Preserve the plugin's registered path and local data.
Refresh your MCP configuration with **Bridge → Copy MCP Configuration** in the new
app. The existing 0.1.1 assets are unchanged and do not include these fixes.

### Alpha boundaries

The app is ad-hoc signed and is not Apple-notarized. It targets Apple Silicon on
macOS 13 or later. A Dev-only account on another owner's view-only file and a full
rerun on the originally reported large work file still need separate validation.
The app cannot determine whether a covered layer is obsolete or which design is
intended; compare in Figma. Follow your organization's policy when using its data.

The attached `release.json`, `SHA256SUMS` and `verification.json` identify the
actual packaged commit and file hashes. The
[verification record](../evaluation/release-0.2.0-acceptance.md) distinguishes
automated checks from observations in the installed app and Figma.
