# 0.2.1 Alpha

[한국어 가이드](../user-guide.ko.md) · [English guide](../user-guide.en.md)

## 한국어

새 미리보기의 가로·세로를 기본 두 배로 높이고, 일반 가져오기를 이어 읽기 가능한
묶음 수집으로 통합했습니다. 5,000개 기본 제한에 걸려 작업을 끝내는 경로를
일반 화면에서 제거했습니다.

- **더 선명한 이미지:** 기본 2배·긴 변 4,096px. 설정에서 최대 4배·8,192px까지
  조정합니다. 이미 저장된 이미지를 자동으로 바꾸지는 않습니다.
- **설정 가능한 예산:** 노드·용량·읽기 시간·응답 대기·연결 유지와 이미지 설정을
  로컬에 저장합니다. 원본 노드는 기본 20만, 설정 상한 100만 개입니다.
- **한도에서 일시정지:** 같은 연결에서 한도를 높이고 계속하면 저장한 부분 다음부터
  읽습니다. PNG와 저장된 묶음을 반복 요청하지 않습니다.
- **받은 자료 자동 사용:** 이미지가 도착하면 같은 화면에서 영역 작업을 시작하고,
  완전한 구조가 준비되면 자동 연결합니다. 미저장 영역을 먼저 저장하도록 기다립니다.
  이미지 실패 시에는 구조를 이미지 없이 사용할 수 있습니다.
- **한국어·영어 안내:** 단일 가져오기와 설정·일시정지·재개의 작업 순서로 갱신했습니다.

앱과 Figma 플러그인을 함께 업데이트하세요. [설치](../alpha-installation.md)와
[업데이트·백업](../upgrade-guide.md)을 따릅니다. 이전 배포 파일은 변경하지 않습니다.

재연결·앱 재시작·원본 변경으로 잃은 읽기 위치의 복구, 여러 시점의 미완료 자료를
통합해 보충하는 기능은 포함하지 않습니다. [복구 진행 상황](https://github.com/neocjmix/figma-semantic-bridge/issues/16)을 참고하세요. 미완료 구조는 승인할 수 없습니다.
원본 디자인은 수정하지 않으며 기존 사람의 승인을 새 원본에 자동 적용하지 않습니다.

전송·파일·보관의 보호 한도는 별도입니다. Figma 내부 메모리와 렌더링 시간은
설정으로 보장할 수 없습니다. 원래 대형 업무 파일 전체와 다른 소유자의 보기 전용
파일·Dev 전용 계정 조합은 별도 검증이 필요합니다. Apple Silicon/macOS 13 이상을
빌드 대상으로 하며, ad-hoc 서명이고 Apple 공증은 없습니다.

## English

New overviews double both dimensions. The normal import now uses resumable
chunked structure rather than the legacy 5,000-node bounded-capture route.

- **Sharper images:** default scale 2 with a 4,096px long edge; settings permit
  scale 4 and 8,192px. Existing images are not regenerated.
- **Saved resource settings:** source nodes/bytes/run/wait/retention and image
  settings persist locally. Source nodes default to 200,000 and allow up to one million.
- **Pause at budgets:** raise settings and Continue within the same valid
  connection from the next unsaved part, without repeating the PNG or saved packets.
- **Automatic evidence use:** draw from received images in the same workspace.
  Complete structure attaches when unsaved region edits are saved. Image failure
  still permits complete structure without an image.
- **Korean and English guidance:** updated for the single import, settings and resume.

Update the app and Figma plugin together; see [installation](../alpha-installation.en.md)
and [upgrade/backup](../upgrade-guide.md). Earlier published assets remain unchanged.

This does not recover a cursor lost to reconnect, app restart or source changes,
or merge partial observations across sessions; follow [recovery work](https://github.com/neocjmix/figma-semantic-bridge/issues/16). Incomplete sources cannot be
approved. Designs stay unchanged and old human approval never transfers automatically.

Transport, file and retention protections remain separate. Settings do not bound
Figma native allocation/rendering. The original large production file and an
effective Dev-only account on another owner's view-only file still need separate
acceptance. Apple Silicon/macOS 13+ is the build target; signing is ad-hoc without
Apple notarization.
