# Figma Semantic Bridge 0.3.0 Alpha

## 한국어

원본 수집이 중단돼도 받은 자료로 작업을 계속할 수 있습니다.

- 저장된 일부 구조와 정확한 원문을 앱 재시작 뒤에도 조회합니다.
- **계속**은 유효한 읽기 위치가 남아 있으면 이어 읽고, 위치가 사라졌으면 비용 확인 뒤 원본을
  다시 검사합니다. 같은 묶음의 반복 전송을 줄이고 기존 이미지·영역·승인은 보존합니다.
- 끝까지 읽힌 부분부터 큰 이미지 위에서 검토합니다. 필요한 미완료 컨테이너는
  그 부분만 준비합니다. 원래 전체 요청은 미완료로 남습니다.
- 숨김·투명한 상위 레이어의 알려진 정보와 관찰 시각을 보존합니다. 부족한 범위는
  승인할 수 없고, 원본 확인과 의미 승인은 계속 사람이 수행합니다.
- 원본 파일 전달을 하나로 통합하고, MCP는 작업 준비·진행·계속·자료 조회 중심으로
  정리했습니다. 이전 파일 읽기와 기존 도구 호출의 호환성은 유지합니다.
- 한국어·영어 UI와 사용 가이드, 상황별 복구 안내를 갱신했습니다.

기본 이미지 2배·긴 변 4,096px, 조정 가능한 수집 한도는 유지합니다. 재연결 후
내용을 확인하려면 저장된 노드도 Figma에서 다시 읽어야 합니다. 단일 불변 버전,
원래 105,837개 업무 파일의 실행·메모리, 다른 소유자의 Dev 전용 보기 권한,
독립적인 사용자 생산성은 보장하지 않습니다.

앱과 플러그인을 함께 업데이트하고 기존 데이터 전체를 백업하세요. 이전 앱만
덮어쓰는 다운그레이드는 지원하지 않습니다. Apple Silicon용 macOS 앱은 임시 서명이며
Apple 공증은 포함하지 않습니다. MIT는 외부 디자인의 재배포 권한을 부여하지 않습니다.

## English

Keep working with received evidence after a source import stops.

- Browse saved partial structure and exact original text after app restart.
- **Continue** resumes a valid reading position or, after confirmation, rechecks
  the source in a new connection. Compact replies reduce repeat transfer while
  preserving earlier images, regions and approvals.
- Review complete parts on the large image, or prepare a needed unfinished
  container separately. The original whole-source request remains incomplete.
- Preserve known hidden/transparent ancestor evidence and observation times.
  Insufficient coverage cannot be approved. Source confirmation and meaning
  approval remain human decisions.
- Use one source-file transfer flow and task-oriented MCP discovery. Older file
  reading and legacy tool calls remain compatible.
- Updated Korean/English interface, guides and recovery scenarios.

Default 2× images, the 4,096px long-edge cap and adjustable budgets remain.
Rechecking after reconnection still reads saved nodes from Figma. This release
does not establish one immutable source revision, original 105,837-node work-file
execution or native memory, another owner's effective Dev-only access, or
independent human productivity.

Update app and plugin together and back up the entire data directory. Replacing
only the app with an older version is not a supported downgrade. The Apple Silicon
macOS app is ad-hoc signed, without Apple notarization. MIT does not grant rights
to redistribute third-party designs.
