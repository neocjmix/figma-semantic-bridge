# Figma Semantic Bridge 0.4.0 Alpha

## 한국어

디자인 가져오기부터 승인한 결과 전달까지 다음 작업을 안내합니다. 새 영역을
저장하면 원본 연결을 함께 준비하고, 영역 승인 후 명세 연결을 이어갈 수 있습니다.
명세는 서로 다른 저장 원본의 문장을 선택해 연결할 수 있습니다. 전달하기에서
실제로 포함되는 승인 결과를 확인한 뒤 JSON 또는 Markdown을 저장합니다.

원본 이름과 영역 이미지를 검토 화면에 표시하고, 세부 좌표·수동 연결·가져오기
기록은 필요할 때 펼쳐 볼 수 있게 정리했습니다. 한국어·영어 가이드를 갱신했습니다.

소수 좌표에서 영역을 분할할 때 발생하던 오류를 수정했습니다. 음수·소수 좌표를
입력할 때 부호와 소수점을 유지하고 입력한 정밀도 그대로 저장합니다. 미저장 영역이나
명세가 다른 탭의 작업·드래그·병합·제안 결과로 교체되는 경로를 막고, 직접 선택한
원본은 영역 위치를 바꿔도 유지합니다. 변경한 영역은 다시 검토해야 합니다.

로컬 진단 로그에 작업과 요청의 시간, 오류 코드·검증 위치·호출 위치를 기록합니다.
웹뷰 오류와 콘솔 경고도 포함됩니다. **브리지 → 진단 로그 폴더 보기**에서 열 수
있습니다. 원문·이미지·토큰·요청 본문·콘솔 인수는 기록하지 않으며 자동 전송은
없습니다. [진단 안내](../local-diagnostics.md)를 참고하세요.

Apple Silicon용 macOS 앱과 로컬 Figma 플러그인입니다. 공증되지 않은 알파이며,
다른 소유자의 Dev 전용 보기 권한과 원래 실무 대형 파일의 성능은 별도 검증이
필요합니다. 원본 이미지와 구조는 서로 다른 시점의 관측이며, 승인은 사람이 결정합니다.

## English

The editor guides you from importing a design to sharing approved work. Saving a
new region prepares its source connections. After approval, continue directly to
linking requirements. Choose exact text from different saved sources in one
specification. Share shows the approved content included in JSON or Markdown.

Source review shows node names and the saved region image. Precision coordinates,
manual matching and import history are available in expandable controls. Korean
and English guides have been updated.

This release fixes splitting regions with fractional coordinates. Coordinate fields
retain negative signs, decimal points and entered precision while typing and saving. It also protects
unsaved regions and specifications during navigation, dragging, merging and AI
generation. Explicitly chosen sources stay selected after geometry edits; the
changed region still needs review.

Private local diagnostics record request and operation timing, error codes,
validation locations and application stack locations, including WebView errors
and console warnings. Open **Bridge → Reveal Diagnostic Logs**. Design text,
images, credentials, request bodies and console arguments are excluded. Nothing
is uploaded automatically. See the [diagnostics guide](../local-diagnostics.md).

The alpha targets Apple Silicon macOS and locally installed Figma plugins. It is
not notarized. Another owner's effective Dev-only view access and the original
large production file remain separate acceptance checks. Image and structure
remain separately timed observations, and approval remains a human decision.
