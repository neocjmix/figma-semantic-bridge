# 사용자 흐름 단순화와 로컬 진단 계획

Figma 원본을 가져와 영역과 요구사항을 연결하고, 사람이 검토한 결과를 전달하는
작업을 하나의 흐름으로 정리한다. 평상시에는 다음 행동을 우선 보여주고, 수정과
복구에 필요한 도구는 펼쳐서 사용할 수 있게 한다. 원본 디자인과 기존 승인은 보존한다.

## 현재 흐름과 개선 결정

| 단계 | 현재 사용자가 겪는 일 | 개선할 흐름 |
| --- | --- | --- |
| 연결과 시작 | 작업 공간 생성, 샘플, 연결 상태가 흩어짐 | 빈 화면에서 작업 공간 생성과 Figma 연결 안내를 먼저 제공 |
| 원본 가져오기 | 대상 확인 뒤 읽기 시작. 완료 후에도 진행 수치와 기록이 계속 보임 | 시작 전 대상과 비용 안내 유지. 완료하면 영역 작성으로 안내하고 세부 기록은 접음 |
| 영역 지정 | 이름, 역할, 부모, 좌표, 저장, 노드 찾기를 따로 처리 | 이름을 입력하고 저장하면 새 영역의 노드 연결까지 준비. 역할·좌표 등은 세부 조정으로 이동 |
| 검토와 승인 | 원본 확인과 의미 승인이 여러 설명 사이에 흩어짐 | 실제 노드 이름과 선택 결과를 중심에 배치. 확인과 승인 단계는 명확히 유지 |
| 명세 연결 | 명세 탭 이동, 원문 선택, 생성, 대상 재선택, 저장, 승인 | 승인한 영역에서 명세 연결로 이동하고 해당 영역을 기본 대상으로 선택. 다른 원본의 문장도 같은 화면에서 선택 |
| 전달 | JSON과 Markdown이 항상 노출되고 미저장 상태도 내보내기 가능 | 전달 버튼 하나에서 저장된 승인 결과와 형식을 안내. 미저장 변경을 먼저 정리 |
| 수정과 복구 | 영역 병합, 탭 변경, AI 응답이 다른 초안을 덮을 수 있음 | 한 번에 한 초안을 편집. 저장 또는 버리기를 거친 뒤 변경. 되돌리기와 기존 수집 복구 유지 |

## 구현 범위와 합격 기준

1. 현재 상태와 다음 행동을 보여주는 진행 안내를 제공한다. 새 사용자에게 연결,
   원본 가져오기, 영역 지정, 검토, 명세 연결, 전달의 순서를 알린다.
2. 정상 흐름의 불필요한 클릭과 중복 선택을 줄인다. 수동 노드 교체, 분할·병합,
   기록 정리, 자료 파일 전달, AI 제안 등은 필요할 때 접근할 수 있다.
3. 한국어·영어 문구를 같은 의미로 정리한다. 상태와 다음 행동을 짧게 쓰며,
   기술적 설명은 세부 정보와 가이드에 둔다. 승인 조건을 문구로 숨기지 않는다.
4. 소수 좌표의 영역 분할 실패를 회귀 테스트로 재현하고 수정한다. 미저장 영역과
   명세가 탭 전환·병합·제안 처리로 사라지는 경로를 차단한다.
5. 요청 식별자, 작업 종류, 실행 시간, 오류 코드·검증 이유·호출 위치를 로컬
   로그에 기록한다. 웹뷰 오류와 콘솔 경고도 관측한다. 원문·이미지·토큰·요청 본문은
   로그에서 제외하며 파일 크기와 보관량을 제한한다.
6. 독립된 합성 작업 공간에서 모든 정상 흐름과 대표 실패·복구 흐름을 검증한다.
   실제 Figma 연결과 패키지 앱 검증은 브라우저 자동 테스트와 별도로 기록한다.
7. 기존 로컬 작업 공간과 미저장 작업을 보존한다. 설치 교체 전에 보존 상태를
   확인하며, 검증하지 못한 외부 계정 권한·실무 대형 파일·실제 모델 품질은 완료로
   보고하지 않는다.

## 작업 순서

흐름 조사와 이 계획을 먼저 확정한다. 이후 편집 화면, 원본 검토 화면, 로컬 로그를
분리해 구현하고 통합한다. 단위·통합 테스트, 전체 브라우저 흐름, 실제 패키지 앱
검증 순서로 진행한다. 발견된 오류는 원인과 재현 조건을 기록하고 수정 후 다시
확인한다. 사용자 가이드와 구현을 맞춘 뒤 로컬 앱을 갱신한다.

## 판단 기록

- 원본 확인과 의미 승인은 서로 다른 판단이다. 자동 노드 연결은 제안 준비이며
  승인으로 취급하지 않는다. 두 검토 단계를 남기고 화면의 다음 행동을 명확히 한다.
- 대형 파일의 비용 안내와 재연결 후 재검사 동의는 유지한다. 무조건 재시도하거나
  가져오기 한도를 자동으로 높이지 않는다.
- 정상 가져오기의 완성된 원본은 그대로 사용한다. AI의 지원 범위를 넓히려고
  구형 가져오기 경로를 다시 기본 선택지로 노출하지 않는다.
- 보고된 분할 오류는 소수 계산 결과가 1을 극소량 초과해 검증에 실패한 문제다.
  비율 계산을 수학적 범위 안으로 정규화하며 원본 좌표를 바꾸지 않는다.
